# Khoaaoo_jiii: Full-Stack Food Delivery & Restaurant Management Platform

**Tech Stack:** Flutter, Dart, Supabase (PostgreSQL, Supabase Auth, Realtime WebSockets), Material 3, State Management (Provider / ChangeNotifier) | [GitHub Repository](https://github.com/talibafridi97-source/Khoaaoo_jiii)

### Key Achievements & Bullet Points for CV:

* **Full-Stack Architecture:** Developed a production-ready, full-stack food delivery and restaurant management ecosystem featuring a customer-facing Flutter mobile app and a real-time web/mobile Admin Dashboard.
* **Backend & Cloud Database Integration:** Engineered secure backend operations using **Supabase**, leveraging PostgreSQL for dynamic menu management, orders persistence, and Supabase Auth for persistent user session handling.
* **Real-Time WebSockets & Live Synchronization:** Implemented Supabase Realtime streams enabling instant audio/haptic order alerts for restaurant managers and live bi-directional order status synchronization (Preparing ➔ Out for Delivery ➔ Delivered) for customers.
* **Advanced E-Commerce Features:** Built robust cart management with food customizations (portion sizes, add-ons, and cooking instructions), promo code voucher calculations, GPS current location picker, and scheduled pre-ordering.
* **User Engagement & Support Modules:** Integrated interactive features including in-app live chat between customers and restaurant managers, live rider tracking cards, and order history re-ordering.
